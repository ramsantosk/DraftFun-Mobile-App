
# DraftFun — Interactive Educational Mobile Application

DraftFun is a Flutter-based educational mobile application designed to help students develop their visualization skills in technical drawing through interactive lessons and game-based learning activities.

The application combines visual learning materials, drawing-related exercises, and interactive challenges to provide an engaging learning experience.

## Project Overview

DraftFun was developed as a freelance mobile application project supporting an academic research initiative.

The application features four learning chapters, each containing instructional materials and interactive activities that help students practice and assess their understanding of technical drawing concepts.

## Key Features

- Four chapters with structured lessons and activities
- Interactive exercises for technical drawing concepts
- Isometric and orthographic drawing activities
- Student account registration and login
- Progress tracking and chapter unlocking
- Leaderboard for student performance
- Audio narration, background music, and sound effects
- Android APK support

## Technologies Used

- Flutter and Dart
- Firebase Authentication
- Cloud Firestore
- Android
